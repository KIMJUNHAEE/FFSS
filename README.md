# 포커포커 섯다섯다

**포커로 패를 만들고, 섯다 적과 맞서는 덱빌딩 RPG**

## 바로 플레이

[브라우저에서 포커포커 섯다섯다 플레이하기](https://kirby47navercom-ai.github.io/FFSS-WebGL/)

별도 설치나 GitHub 로그인 없이 실행할 수 있습니다. 첫 접속은 WebGL 데이터를 내려받느라 잠시 걸릴 수 있습니다.

## 게임 소개

섯다 세력에게 침공당한 포커포커 마을을 되찾기 위해 세 개의 막을 돌파하는 게임입니다. 플레이어는 포커 카드로 족보를 만들고, 붉은 패와 검은 패를 활용해 공격과 방어 수치를 구성합니다. 적은 섯다 패와 고유 기술을 사용하며, 전투 사이에는 필드를 탐색하고 카드와 장비를 강화할 수 있습니다.

## 주요 특징

- 포커 족보와 카드 색상을 이용한 공격 및 방어
- 적마다 다른 섯다 패, 전용 카드, 행동 기믹
- 카드 교환, 연마, 성장과 장비 조합
- 일반 전투, 중간보스, 광땡 보스로 이어지는 3막 구성
- 브라우저에서 바로 실행되는 Unity WebGL 빌드

## 실행 방법

1. 위의 플레이 링크를 엽니다.
2. 첫 로딩이 끝나면 `새 게임`을 선택합니다.
3. 규칙 안내를 확인하고 게임을 시작합니다.

## 소스 코드

전체 Unity 프로젝트와 커밋 기록은 이 저장소에 포함되어 있습니다.
